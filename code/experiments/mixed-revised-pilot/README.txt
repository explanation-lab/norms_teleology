NORMS TELEOLOGY — REVISED MIXED-CONDITION PILOT
Version: norms-teleology-mixed-revised-pilot-1.0.3

Extract the entire ZIP, keep its folders together, then double-click index.html.
No installation, server, internet or sign-in is needed. JavaScript must be enabled.
The reviewer panel switches among all six animal-condition pairings, jumps to
any animal or screen, and shuffles animal/question order.
Try participant flow opens participant.html without reviewer controls.

Every participant sees Virdexes, Nalks and Marvins once each, with exactly one
control, one survival-benefit and one ecological-benefit case. The animal-condition
pairing is selected randomly in participant previews, independently of animal
presentation order. The same randomly selected question order is reused for all
three animals. All assignments and orders persist on reload.

Uses all three revised cases from the November 2 review, including Nalk fish and
the single large ground-contact spike on each Marvin hoof. The Marvin spikes are
darker for visibility. Nalk questions omit “dense”; the case description is unchanged.
Importance statements use “Having spots/hair/spikes makes [animal] especially
important creatures.” Value statements also use the short feature names
spots/hair/spikes, without repeating the location of the feature.
Five questions per animal: ought, something wrong, special importance, special
value, and meant to do. There is no best-to-have question. Each rating uses the
same labeled seven-point scale. There are no written explanation questions.
Case text and both images remain above each question. Consent, instructions,
and optional demographics follow the existing study. Duration is provisionally
about 5 minutes and should be confirmed before recruitment.

Local JSON and ratings CSV include actual per-animal benefit_condition, pairing,
item/question orders, exact wording, ratings. Console launch
conditions are pairing codes p1–p6; benefit_condition identifies control/survival/ecology.
