NORMS TELEOLOGY — STUDY 1, THREE-ANIMAL REVISION
Version: norms-teleology-study1-2.1.0

REVIEW
Extract the entire ZIP and double-click index.html. No installation, internet
connection or server is needed. Keep all the extracted files and folders together.
Use Condition to switch between Control, Survival benefit and Ecological benefit.
Use Screen to jump directly to any animal's story or any of its five questions,
as well as consent, instructions, demographics and the end screen.
Show explanation box previews the text box without entering a rating.
Try participant flow opens a local participant preview with no review controls.
Review and local-preview responses are never submitted to the study console.

DESIGN
Each participant sees Virdexes, Nalks and Marvins, in randomized animal order.
The assigned condition stays the same across all three animals. Animal order and one randomized question order are saved for reload recovery.
Each participant sees the same question order for every animal. Reviewer navigation uses Virdexes, Nalks, Marvins.
Each animal has a story/image screen and five rating/explanation pairs:
Importance, Survival importance, Value, Significance, Something wrong.
The case and matched images stay above each question. All 15 questions use the
same fully labeled seven-point agreement scale. Choosing a rating reveals the
explanation box; both a rating and a nonblank explanation are required to continue.
Optional Purpose Norms demographics appear once, after all three animal items.
Consent -> Instructions -> [Story + five questions] x 3 -> Demographics -> End.

DATA
JSON includes animal order and all trial records. Ratings CSV includes item_id,
item_position, measure, question_id and overall question_position. Question IDs
combine species and measure; measure alone identifies the parallel question.
A separate demographics CSV is available. All local exports are marked as preview.
